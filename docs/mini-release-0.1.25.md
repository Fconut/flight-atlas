# 小程序 0.1.25

日期：2026-11-14。

## 本轮更新

- 首页海报统计排版向默认版对齐，起降次数放在标题中，行高随内容计算。最常乘坐航线按方向分别计数并展示前两名。
- 航司显示改为普通字体代码标识，保留代表色及可读对比度；移除小程序中的官方航司图形及加载代码。
- 徽章详情、选择分享记录、公开查看及卡片／海报统一轻量分割线与渐隐底色；顶部操作按钮固定横向排列。

## 自检精简

- 徽章详情、分享页、卡片及海报共用一次遍历的统计函数；航司别名按同一航司计数，日期仅从当前记录／分享选集计算。
- 页面直接把原始航班号交给代码组件，删除拼接后再次拆分的重复逻辑。
- 删除未使用的海报参数、包装函数、样式及空提示占位。保留历史素材许可审计，不改动网页资源。
- 保留统计范围、分享快照固定、30 秒生成频率控制、账号隔离和图片内存边界。

## 验证

- 240 项测试通过，覆盖选集统计、单向航线、账号与分享隔离、二维码缓存、图片尺寸上限、撤销删除等。
- 101 个客户端脚本语法检查通过；23 个注册页面、静态引用检查无缺失。
- 使用虚构航班重新生成并检查徽章卡片与海报。
- 本轮未重新执行手机上的人工点击验收；上传后的开发版可继续真机检查。
