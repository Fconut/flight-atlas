# 扩大搜寻结果

2026-11-14，对上一轮 31 家文字兜底航司进行官网、品牌手册及图库核对。

找到 17 家不含完整航司名称的图形候选：10 家为矢量或至少 64 像素图像，7 家仅为 16–48 像素网站图标。官网图标可验证来源，但本次未取得新的航司公开再使用授权；候选不计为可无条件商用素材，未接入小程序。运行中的 50 家图形、31 家文字兜底保持不变。

质量门槛仅描述图像尺寸，不代表授权或品牌规范已通过。济州的 j 属单字母图形；荷航 KLM、全日空 ANA、葡航 TAP、日越 JTA/JAL 等仍包含品牌名称，不采用。亚航当前官网 M/MOVE favicon 未能作为承运航司独立标志确认。
