# 航司图片来源与许可核对

核对日期：2026-11-14。范围：小程序现有 81 张图片，网页版保持原样。

81 张原图均通过 Git blob SHA-1 与记录的上游版本逐字节匹配。原仓库 README 声明 MIT，但未提供各航司的授权链或单张许可。新图来自固定版本 Soaring Symbols：仓库 MIT 许可原文已保留；上游明确声明商标与著作权仍属航司，不能视为已获航司授权。

本次 50 家改为不含完整航司名称的独立图形；31 家没有符合要求的可用图形，移除小程序原图并使用代码／航班号兜底。未从品牌官网或其他商业库抓取素材；未裁切旧图、改色、生成近似商标。原图仍保存在网页资源目录中。替换图形不代表消除法律风险。

逐张文件记录、来源链接、版本、原图／新图 SHA-256、处理结果见 inventory.json。
