# 自动回归检查

运行 `node --test tests/*.test.cjs`，需要 Node.js 24，无需安装依赖、连接 Supabase 或提供密钥。

提交代码及 Pull Request 会运行 Regression checks：检查应用脚本语法，然后执行全部测试。CI 不修改或部署用户数据，GitHub Pages 原有工作流保持不变。检查失败时，在 Actions → Regression checks 查看失败的测试名称和断言。

覆盖：导入后地图失败的提示、编辑与地图资源加载隔离、收藏册详情起飞时间排序、重复导入、最新非空机型更新、中文表头和日期、单向航程与航班号、大圆距离、往返合并与总里程、未来行程、未知机场、机型别名与子型号、收藏次数与首乘日期、备份恢复与账号范围、云端确认保存、取消、版本冲突和本地副本失败。

纯函数测试从当前应用文件加载实际逻辑，使用仓库中的 D3 计算距离；DOM、邮件、真实账号的跨设备操作及 PNG 视觉效果仍需要浏览器或人工验证。源码切分边界变化时测试会明确失败，需要同步调整测试入口，而不是跳过检查。
