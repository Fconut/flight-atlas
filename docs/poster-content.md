# 首页海报内容定制

“海报内容”内可自定义统计区标题，最多 20 个 Unicode 字符；空白输入使用“我的足迹”。标题纳入本机偏好、云端草稿、内容变化检测与三方合并。“恢复默认”同时还原标题和默认细项。仅地图模式不显示统计区标题。新分享固定保存生成时的标题，旧分享缺少标题字段时使用默认标题；分享卡片使用自定义名称，未自定义时保留原卡片标题。新增功能已通过 227 项测试及原有流程回归。

当前默认版保持原统计区绘制。海报内容设置提供 27 个独立数据项，按六组展示，每项带当前数据预览；null 表示默认，空数组表示只保留地图。旧的八模块选择会迁移到对应细项。

## 数据项

- 飞行总览：累计里程、航班次数、机场数量、航司数量、不同航线数量、机型数量。
- 飞行时光：首次飞行日期、最近飞行日期、飞行最多的年份、月份。
- 机场足迹：最多起降、最常出发、最常抵达、首次出发、最近抵达机场。
- 方向足迹：最北、最南、最东、最西机场。
- 航线纪录：最长、最短、最常飞航线。
- 航空偏好：常乘航司排行、常乘机型排行、波音、空客和其他常乘机型及其飞行次数。

## 版式

沿用默认版的“我的足迹”标题、渐变底、细分隔线、大数字与小单位层级。各项先按 poster-item-rules.md 声明内容与面积，再由四列栅格拼版。紧凑总览优先，同组相邻、组间固定顺序；仅在组内按面积放置，小项填空。方向足迹独立成组，四列一排或两列两排，不插入其他信息。最长、最短各保留两条不同航线；排行展示前三名。机场名称、代码、次数及坐标分层，每条航线的机场名称独立成行，代码、航班号及距离分层，数值独立对齐。字体缩放及省略沿用 poster-type 的防溢出能力。地图投影及尺寸不随统计选择变化，只调整下方统计区高度。

## 保存与分享

选择纳入本地偏好、云端草稿、内容变化检测和三方合并。首页预览、高清导出和新地图分享共用结构化统计；分享只携带已选细项。用户选择首次或最近飞行日期时，分享展示完整日期，不额外限制为年份。未选择的具体日期不加入新统计快照。旧分享采用兼容绘制，保留当时已生成的内容。

统计复用已校验、去重并应用统计范围的结果。地图连线与航线数量仍往返合并；最常乘坐航线按方向分别计数，起降次数均计入机场；未来行程不解锁徽章。同日首末机场按已有起飞时间排序，缺时间的记录按稳定次序处理。

## 检查

222 项测试通过：细项迁移、缺失值、零值、完整日期、保存合并、客户端/云端快照一致，以及单项、稀疏、全选和固定随机组合的高度与几何检查。虚构 50 班样例生成五种视觉组合；默认版与改动前逐像素一致。界面触控和真机文字效果仍需人工验收。

另有 600 组不同密度选择验证矩形不重叠，选择组合不能减少最长、最短航线的条数。详细的 27 项内容、基础宽高及数据不足处理见 poster-item-rules.md。

云端仅增量更新 atlas-share/domain，保留现有限流和小程序码规则；不提交审核。

已移除“已解锁徽章”选项及对应统计。方向足迹的四列和两列两排均有真实机场名样例与测试。

留白统一为同组行间至少 8、组间 12（1080 设计坐标），恢复逐行细分隔线。两列方向布局同样有独立行间留白，分享渲染缓存版本已更新以免复用旧的紧密图片。视觉样例位于 outputs/海报留白-默认组合.png、海报留白-全选.png 和海报留白-两列方向.png。

厂商常乘机型采用排行格式：波音、空客、其他各列出最多三款机型，按次数降序、名称稳定排序，右侧对齐次数；不足三款按实际显示。沿用常乘机型排行的半宽详情面积与行距。整体排行与厂商排行分成连续的两个子组，避免相互穿插。228 项测试通过。

最常乘坐航线按飞行次数降序展示前两条不同航线，次数相同按出发、抵达机场代码稳定排序；去程、回程各自计数与排名。两条使用与最长、最短航线相同的半宽详情版式，一条时按实际显示并收起多余高度。229 项测试通过。

两条航线的响应式规则：当选项可使用整行宽度、分成两列后仍能保留现有字号与全部名称、代码和数值时，改为一行两列，高度收为 96；半宽并排或长文字放不下时继续上下两条，高度为 148。适用于最长、最短和最常乘坐航线，条数与排序不变，后续内容同步上移，不保留空洞。230 项测试通过。

2026-11-14：最常乘坐航线改为按“出发机场 → 抵达机场”分别计数后取前两名。仅使用当前统计范围内已校验、去重的记录；最长、最短航线、地图连线及航线数量口径不变。客户端与云端分享生成逻辑一致，已生成的分享快照保持原内容。
