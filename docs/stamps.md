# 旅途印章

2026-11-17，新增100枚印章，10系列，每张海报最多使用1枚。使用按原稿逐格重绘的透明PNG；收藏详情与海报共用同一份素材。

## 收藏与海报

- 收藏tab新增「旅途印章」收藏册；系列以册子呈现，未拥有系列及印章置灰。点进系列使用原生页面栈，返回先回系列，再回收藏首页。
- 收藏详情仅添加／移除首页印章候选，不直接切换海报。候选上限6枚；首页使用中的印章不能移除。
- 首页「海报装饰」分别选择配色和印章，可选「不使用印章」。配色候选上限6款，每张海报最多1枚印章。
- 默认、定制统计区的标题右端预留印章位置，长标题避让；仅地图或旧版分享统计布局把印章放在顶部留白。保留素材原有配色。
- 选择作为posterStamp偏好进入本机状态、备份、跨设备合并和分享快照；收藏归属仍由服务端签到台账恢复，不因添加、移除或切换而变化。

## 固定签到奖励

配色奖励调整为累计1、8、15……386天，共56款。新增印章奖励累计第2、9、16……415天，共60款。两条序列无重合，不要求连续签到、不按周或年份重置。已达标的印章可补领，不重置现有天数，也不自动领奖、添加或应用。

`cloudfunctions/atlas-checkin/stamp-rewards.json`是印章奖励唯一来源；顺序穿插10个系列，每系列6枚。其余40枚只展示，获得方式待开放。已发奖励不可通过重新排列清单改写。

客户端声明planVersion 5，服务端同时兼容旧客户端的配色计划4。仍使用同一个私有`mini_atlas_checkins`集合和事务；没有新增查询、定时器或集合，每个累计日幂等领取。保留被旧配色顺序发出的权益。

## 素材维护与性能

- 唯一图案目录：`design/stamps/catalog.v1.json`；原图及来源校验记录在`design/stamps/masters/`与`artwork.v2.json`。弃用的矢量实现仅留在`design/stamps/archive/`，不进入小程序。
- `node scripts/stamps/build.cjs --images`生成轻量目录、60项客户端奖励、100张384像素透明PNG和小图总览；`--check`验证目录、奖励、100份源图哈希、分包图片清单和体积上限。图案目录运行端压缩为名称／图案元组，再恢复对象，避免重复描述。
- 小图仅用于日历、候选和册子封面。印章列表和详情使用按需分包PNG；海报按需加载并缓存所选PNG，不请求云存储图片。
- 高清图分为stamps0至stamps3，每包25枚、约1.0–1.3MB。100枚印章不在启动时逐一解码，也不随海报生成调用云函数。
- 新增测试覆盖计划并行、60枚固定奖励、幂等与旧进度保留、旧客户端协议、候选上限与在用保护、备份及分享传递。预览编译与模拟测试不替代真机领取验收。
