# 海报统计区的整体视觉规则

地图是主视觉，统计区采用一块连续的渐变底，不用重复的模块大标题或密集表格线。默认版保留现有画面；以下统一约束自定义内容。

1. **阅读顺序**：总览 → 时间 → 机场 → 方向 → 航线 → 航空偏好。同类内容连续，方向足迹整组保持四列或两列两排。
2. **信息层级**：标题 22，指标标签 14，大数值 27，单位 14，辅助信息 13；日期为 23，机场名 19。机场代码和距离用强调色，其他辅助文字用次级色。
3. **间距分层**：同行由统一列线对齐；同组上下行留出至少 8 的空白，不同组间留出 12。这里的数值基于 1080 设计坐标，随输出宽度等比缩放。
4. **分隔线克制**：每行保留细线，连续区域合并绘制，留出适量空白；不同高度的内容按实际范围画线。线不紧贴坐标、日期或次数。航线内部的记录分隔线单独控制。
5. **详情区节奏**：最长、最短各两条航线；两条记录的主文字基线间距为 66，排行行基线间距为 36。内容条数不能为适应面积而减少。
6. **留白是布局的一部分**：绘制不能事后凭感觉增加边距；面积计算同时预留行间、组间和底部空间，首页、高清图和分享共用相同结果。
7. **选择变化时保持视觉稳定**：缺失组收起，其余组顺序不变，地图尺寸和字体层级不随选项数量缩小。尾行允许均衡扩宽，但不通过放大字体填满空白。

已使用默认组合、全部细项、长名称两列方向和原默认版生成实际海报检查；原默认版逐像素比较一致。自动检查同时覆盖行间距、组间距和矩形不重叠，真机字号与点击体验仍需人工确认。

航线对齐修正：机场名称与距离／次数共用主行，右侧数值区固定 132，间隔 16；代码和航班号放在下方辅助行。航线名称最低字号 14。整行两列的适配判断同时预留这块数值空间，长名称不满足时保持纵向两条。数据条数与排序不变。231 项测试通过。

原版节奏对齐：起降最多机场的次数放在标题中，主体只保留机场名和代码。两行总览实际高度 80，带坐标或日期详情的项目高度 88；布局按实际内容计算，避免用统一高度撑出空白。分割线位于下一行起点上方 22，保持线上下的阅读间隔。

航线内部横线：以小标题与其上方分割线的可见留白为参照，按航线名称经过宽度适配后的字形高度定位横线；不改变航线主辅行位置。运行环境缺少字形高度时使用字号比例回退。
