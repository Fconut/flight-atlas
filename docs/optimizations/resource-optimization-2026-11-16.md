# 云资源调用优化（2026-11-16）

本轮只调整客户端重复请求，不改数据库权限、签到事务、备份版本冲突校验或分享生成30秒限频。没有读取生产资源点账单，不能将代码调用次数换算成实际费用。

- 启动与前台事件共用首次备份读取，避免排队的启动任务再次触发整轮读取。
- 本机内容未修改时，前台／网络事件复查云端从30秒改为5分钟。实际本机修改仍2秒合并保存，退后台仍提交未保存数据；版本冲突仍读取、合并后重试。
- 收藏入口及系列页签到状态复用30分钟；签到页5分钟；北京时间跨日失效。签到、领奖直接请求服务端。跨设备领取在收藏页可能延后最多30分钟显示，在签到页最多5分钟。
- 签到状态失败冷却60秒，防止切换页面连发失败请求；用户手动重试绕过冷却。状态并发请求按账号合并。
- 分享只读快照复用5分钟、小程序码复用30分钟，仅内存缓存；按环境、账号、操作和参数区分。最多8项、序列化内容最多2Mi字符；失败不缓存、返回独立副本。分享创建始终由服务端执行，保留并发合并。

## 验证

新增／更新测试覆盖：首次启动只读一次、5分钟复查边界、其他设备版本合并、本机修改仍保存、签到主动与被动缓存差异、跨日失效、失败冷却与手动重试、分享重复读取与缓存副本隔离、账号切换、码环境版本隔离、创建不缓存。

实际资源消耗需在云开发控制台对比。开发版已有 getApp().cloudUsage.snapshot()/reset()，仅统计内存中的函数名和动作，不记录航班或请求内容，不上传日志。
