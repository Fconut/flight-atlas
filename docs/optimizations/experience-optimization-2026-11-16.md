# 页面体验优化（2026-11-16）

- 收藏页和配色页只传递变化的数据字段。无变化刷新不重复传输整组卡片，单独错误恢复也不会重传图片绑定。系列内页面不再计算、传输不可见的系列封面列表。
- 收藏与配色页面隐藏后忽略后台页面刷新，回来时以现有缓存重新检查。
- 收藏首页导航期间忽略重复点击，失败后恢复操作；返回首页恢复导航入口。
- 签到读取与签到／领奖操作分开。已缓存时可在后台读取过程中预览及关闭奖励弹窗；无缓存时显示读取状态，不把未知天数显示为0。
- 签到页只传输实际展示字段，不把云端grants、revision、pool等元信息发送到视图；内容相同不重复更新30格网格。
- 缓存签到状态按当前北京时间重新判断今日是否签到，避免跨日短暂显示昨日的“已签到”。
- 奖励来源按天数索引匹配已领记录，替代重复扫描。奖励格留足领取按钮空间。

验证覆盖重复刷新零列表传输、错误字段单独更新、缓存跨日、视图不含云端元数据、后台刷新仍能预览／关闭、导航防重与失败恢复。未宣称真机耗时或帧率提升，需要真机检查体感。
