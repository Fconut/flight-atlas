# 产品措辞约定

本轮覆盖航班管理、导入核对、数据检查、海报设置、机型收藏、回放、分享及云端错误提示。保留品牌标题、字段标识、表格表头、机场与航空公司数据字典、错误代码和删除确认口令。

| 概念 | 使用方式 |
|---|---|
| 航班记录 | 管理、导入和删除以“条记录”计数，可能包含未来或未纳入统计的航班。 |
| 飞行次数 | 根据当前统计范围计算；首页范围提示显示实际纳入统计的航班数。 |
| 起降机场 | 统计航班两端的机场，机场数量按不同代码去重。 |
| 起降次数 | 同一机场作为出发或到达机场，每次计一次，不等同于旅行次数。 |
| 航线 | 默认统计往返合并；单枚机型分享沿用单向统计，并明确标注“单向航线”。 |
| 常乘机型 | 描述用户乘坐最多的机型，取代容易产生歧义的“常飞机型”。 |
| 方向足迹 | 使用“最北／最南／最东／最西机场”，涵盖出发和到达机场。 |
| 账号 | 统一使用“账号”；云端保存与微信账号关联。 |
| 选填 | 用于非必填输入；“推荐”“候选”用于供点选的内容。 |
| 待核对／待修正／待完善 | 分别用于需要确认、格式或必填内容有问题、选填信息可补充的状态。 |
| 取消全选 | 只取消记录勾选；删除操作明确写“删除”，不以“清空”代替。 |

## 提示原则

- 错误说明当前状态，并给出用户实际可执行的下一步；自动登录流程不再要求手动“连接微信云端”。
- 记录发生变化与微信账号切换分别表达，避免用模糊的“身份已改变”。
- 同步未完成时提示联网重试，不要求用户寻找已不存在的手动保存入口。
- 导入成功使用“已保存 N 条记录”，同时涵盖新增和更新；核对页明确未选中的记录不会导入。
- 分享标题使用“我的 N 次飞行，累计 X 公里”，保留数字千分位。
- AI 整理提示词只调整中文表达和代码名称的格式，不更改输出表头、核对约束或证据要求。

逐处变更清单保存在工作区 outputs/措辞调整清单.json。统计算法、限流规则及三次删除确认流程未改动；首页范围旁的数字改为读取已有的实际统计总数。

设置入口统一为“海报内容”“海报配色”“机场标注”；机场搜索使用“机场、城市或代码”等直观说明，保留 IATA/ICAO 数据与匹配规则。
