# 小程序 0.1.40

2026-11-19开发版上传成功，尚未提交审核。主包1,969,509字节，总包28,902,736字节。

## 本轮变更

- 首页先异步加载对应印章分包，再读取透明PNG，避免首次使用必须先进入收藏。
- 分享图片明确指定携带分享编号的入口，海报、徽章和收藏册分别打开分享快照，不打开接收者自己的数据。
- 订单截图按实际联程航段拆分，兼容机场名称中的OCR空格；缺少年份不猜测，泛称波音737不推断子型号。
- 缺少年份、未识别日期与无效日期分别提示；保留原核对卡片布局。
- 页面就绪后启动识别，减少onLoad阻塞；重复返回与确认导入后的换图操作受到保护。
- 入口为“用提示词整理航班截图”，说明为“复制提示词，制作可导入的 Excel”。详情页及完整提示词已按用户要求恢复。小程序本身不提供生成式AI服务；图片识别属于现有OCR功能，不能与提示词说明混称。

## 验证

- 296项小程序及云函数逻辑测试通过。
- 100份印章原稿哈希、分包资源清单、奖励清单校验通过；结构检查无缺失引用。
- 用户确认截图导入、分享图片链接和首页印章的本轮真机验证无问题。此记录不推断所有设备均已覆盖。
- 上传结果存于工作区outputs/upload-0.1.40.json，不包含个人航班数据。
