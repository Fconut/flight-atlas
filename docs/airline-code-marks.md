# 航司代码标识

航班列表、收藏徽章乘坐记录、徽章分享页面及卡片／海报共用同一套文字标识规则。

- 使用普通字体显示规范化航司代码，统一浅底、细边框及圆角，不仿制航司字标或图案。
- 沿用已核对的代表色；亮色只适当降低明度，使文字与底色对比度至少达到 4.5。未知航司使用中性灰绿。
- 与标识对应的前缀不再在航班号码中重复；ICAO 别名可规范化为 IATA。航司与号码前缀不一致时保留原号码，不擅自改写数据。无航司时保留完整号码。
- 仅改变显示，不修改保存的航班记录、分享快照或筛选逻辑。
- 小程序不再打包航司官方图形图片；历史图片来源与许可审计保留在 docs/legal/airline-logos，网页版未改动。
- 旧组件路径保留以兼容页面注册，其实现已改为文字组件；分享画布复用相同的号码与配色函数。

徽章分享展示更新：选择记录页与公开查看页采用小徽章标题、简洁统计、航司浅色渐隐底及分割线列表。勾选只改变公开记录范围；最早日期从实际公开记录中计算，显示为“最早记录”。对应卡片及带码／无码海报同步样式。详情顶部操作区显式固定横向、不换行，分享与关闭按钮各 80rpx。

配色模型已更新为两个角色：代码用主色，背景用浅化后的次色；移除细线装饰和代码块彩色边框。详见 airline-palettes/配色规则与全量表.md。
