# 配色收藏：首批100款与扩展规则

状态：设计评审，尚未接入线上、未限制现有配色、未启用广告或支付。

## 首发内容

- 10系列各10款，4款免费：深海鎏金、晴空来信、松林微光、海盐清风；96款待解锁。
- 原有10款色值保留，新名称仅用于设计评审。每个组合是固定色值，不在运行时随机生成。
- 100个编号及名称唯一；路线与背景对比度至少3:1。对比度通过不代表审美验收通过，近似配色和手机尺寸仍需逐组复核。
- 分类是内容编排，不直接等于商品；尚不创建价格、OfferID或广告位。

## 内容与权益分离

1. 配色有永久ID、名称、系列、标签、明确色值、发布状态与版本。名称和排序可修改，ID不能回收复用。
2. 系列用于浏览；商品SKU独立维护，绑定明确且固定的配色ID集合，避免购买后因分组变化丢失权益。后续扩充商品是否补赠须单独约定，不能默认购买一个系列就永久得到其未来所有内容。
3. 权益台账独立存储：用户身份、配色ID、来源广告/购买/赠送、来源交易/奖励事件ID、时间及退款关联。发放事务幂等，不接受客户端自报已付款。
4. 支付以服务器确认交易为准；广告领奖仅凭前端播放完成回调不够，必须确认平台可用的可信验证机制，再决定风控和发放方式。
5. 退款按对应交易回收权益；若同款另有有效的广告或购买来源，不误删其他来源权益。
6. 已拥有配色从购买包内明确标注，不重复当作新奖励；付款前列清包含项及重复项。退款处理与永久权益的例外须事先告知。

## 展示与发现

- “我的”：当前配色海报→发现配色→我的收藏。完整库按系列展示，每次只加载当前系列或可见卡片，不同时创建100个Canvas。
- 默认入口优先展示已拥有及4款免费；未解锁同样可预览真实海报。预览状态独立于正式应用状态，返回不误改当前配色。
- 广告领取应先展示明确的目标配色，避免重复；先不做随机付费、碎片、积分、强制广告后等待。
- 卡片从实际海报渲染器裁取地图区域，同投影、同数据、同航线样式；保持原比例。示例样本固定。用户自己的预览只在打开详情时生成。
- 缩略图缓存键包含配色ID/版本、渲染器版本、样本版本；海报用户预览另加数据与标注偏好。内容列表不包含用户私有航班。

## 数据与性能

- catalog schemaVersion用于结构兼容，catalogRevision用于目录变化，单款revision用于色值变化。未知字段忽略，未知状态不展示，缺失目录回退免费默认配色。
- 首版目录可随包发布，仅几十KB；权益独立云端保存并本地缓存，页面切换不重复拉取。
- 目录下架只影响新领取，不抹除历史权益。色值变化如影响既有购买视觉，应发布新版本并保留旧版可用，不能静默替换。
- 颜色无法保密，也不能靠隐藏十六进制值保护权益；校验放在应用、导出、分享服务入口。公开预览是产品策略，不宣称防复制。
- 不为100款预览上传100张用户海报，不引入新的地图绘图实现。
