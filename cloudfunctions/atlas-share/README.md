# 飞行足迹分享

使用已有仅管理端可读写的 mini_atlas_drafts 集合，share- 和 share-owner- 为独立文档前缀；不开放数据库读权限。create 仅从当前微信用户的已保存草稿计算历史足迹，客户端不能指定他人的账号或传入公开内容。domain/share-snapshot.js 与小程序同源，公开数据采用字段白名单，不包含航班号、具体日期、机型、文件名和未来行程。

分享编号由 128 位随机数生成，持有链接即可读取这份公开快照。分享不设置自动到期时间，不提供分享记录列表和撤销操作；后续修改航班不会改变旧快照。相同内容再次生成时复用最近一次分享链接，避免重复存储；不设置每日分享次数限制；不同内容的新快照按微信账号间隔 30 秒，相同内容按规范化摘要复用。小程序码按快照 ID 和 develop/trial/release 分别缓存，缓存读取不限频；生成使用 30 秒租约防并发，成功后更新账号频控时间，失败释放租约且不延长冷却。最新快照创建后可立即生成对应码。仅创建人可生成对应小程序码。普通读取不更新或恢复任何航班数据。旧记录中的 expires 字段不再参与读取或小程序码生成判断。

云函数通过 cloud.openapi.wxacode.getUnlimited 生成小程序码，config.json 声明对应权限。小程序码暂不可用时，好友卡片与普通海报仍可使用。建议超时 20 秒、内存 256 MB；开发者工具可能不会应用 config.json 中的资源配置，需要部署后核对。未发布页面的真实分享范围仍受微信开发版/体验版访问权限约束。

共享域代码更新后需同步小程序 lib/share-snapshot.js、flights.js、airports.js、d3.js 到 domain。发布前核对接口隐私指引与公开内容预览。不要把整个账号草稿或分享者 OPENID 放进路径、图片或响应。

整本收藏分享使用 kind=collection：仅公开已解锁徽章、各机型乘坐次数和制造商汇总，不含日期、航班号、机场或未来行程。单枚徽章分享使用 kind=badge：只公开用户明确勾选的历史航班日期、航班号及航线，服务端核对选择内容与当前草稿一致。两类分享均为固定快照；收藏分享和单枚徽章分别进入独立只读页面。
